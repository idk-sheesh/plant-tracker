# Plant Tracker

Plant Tracker est une application mobile en cours de développement pour aider à suivre les plantes, les espaces de jardinage et les interventions du quotidien.

## Objectif

Proposer un carnet simple et local pour centraliser les informations utiles à l'entretien des plantes :

- organiser ses plantes et ses collections ;
- noter les arrosages, l'entretien et les observations ;
- conserver un historique pratique sur l'appareil.

## Statut

Projet personnel en préparation. Le code source n'est pas publié pour le moment.

## Technologies

Flutter / Dart

## Confidentialité

L'application est pensée pour fonctionner localement et rester centrée sur les besoins du jardinage personnel.
